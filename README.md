## What is Lyceum?

Lyceum is an open [agent skill](https://code.claude.com/docs/skills) (a `SKILL.md` package) that
teaches Claude Code, ZCode, Codex CLI, or any SKILL.md-compatible agent to build and edit
**academic presentation decks that stay natively editable in PowerPoint** — real text boxes,
real charts (right-click → Edit Data works), real tables, real shapes.

It does not ship one style with different labels. It ships **six complete scenario systems**,
each with its own page skeleton, design tokens, content playbook, and theme variants — because
a lab group meeting and a thesis defense are different genres, not one deck with different
colors:

| Scenario | 中文 | Talk | Pages | Reference |
|---|---|---|---|---|
| Lab group meeting | 组会汇报 | 15–40 min | 8–20 | [`references/group-meeting.md`](skills/lyceum/references/group-meeting.md) |
| Conference talk | 学术会议报告 | 12–20 min | 12–18 | [`references/conference.md`](skills/lyceum/references/conference.md) |
| Progress / mid-term / final report | 科研进展·中期·结题 | 15–30 min | 12–25 | [`references/progress.md`](skills/lyceum/references/progress.md) |
| Thesis defense | 学位论文答辩 | 15–40 min | 20–40 | [`references/defense.md`](skills/lyceum/references/defense.md) |
| Research proposal | 开题报告 | 10–20 min | 15–25 | [`references/proposal.md`](skills/lyceum/references/proposal.md) |
| Paper reading / journal club | 文献分享 | 20–45 min | 12–25 | [`references/paper-reading.md`](skills/lyceum/references/paper-reading.md) |

Every scenario carries **3 theme variants** (18 design systems total) built on a five-layer
visual model — paper-toned page, content cards, stepped ink ramp, one accent, dark-cover
sandwich — plus a CJK/Latin **split-run typography rule** so numbers stop looking like
afterthoughts.

## Design highlights

What Lyceum itself provides:

- **Six academic scenario systems** — group meeting, proposal, thesis defense,
  paper reading, course report and progress review — each with three complete
  design themes.
- **Programmatic QA gate** — overflow, overlap, placeholder, font and
  editability audits run on every build, so a deck that passes QA is safe to
  ship without eyeballing every slide.
- **Natively editable output** — charts are real charts, tables are real
  tables; nothing is baked into screenshots.
- **Content method built in** — action titles, the ghost-deck test and
  assertion→evidence mapping, plus per-scenario guidance for presenting
  negative results and limitations honestly.
- **Chinese academic typography** — CJK/Latin split runs and punctuation rules
  handled by construction.
- **Portable** — a SKILL.md plus two ordinary dependencies (`python-pptx`,
  `pptxgenjs`); if the agent already has an official `pptx` skill installed,
  Lyceum delegates syntax-level execution to it and layers the scenario
  systems on top (see [`SKILL.md`](skills/lyceum/SKILL.md)).

## Quick start

Requirements: an agent that supports SKILL.md skills, plus `python-pptx` (QA) and `pptxgenjs`
(builds).

```bash
# Claude Code
git clone https://github.com/<you>/lyceum.git
mkdir -p ~/.claude/skills && cp -r lyceum/skills/lyceum ~/.claude/skills/

# ZCode / Codex CLI / any .agents-compatible agent
mkdir -p ~/.agents/skills && cp -r lyceum/skills/lyceum ~/.agents/skills/

# optional QA + build deps
pip install python-pptx && npm install -g pptxgenjs
```

Then just talk to your agent:

```text
帮我准备下周三的组会PPT，主题是对比学习在小样本分类上的进展，
上周复现了基线，这周有增强策略对比和消融实验，另外Mixup有bug要讨论

用 Lyceum 做一份硕士答辩PPT框架，研究方向是联邦学习里的异构模型聚合，
创新点有三个，给我深一点的学院风配色

Journal club 分享这篇 NeurIPS 论文，重点讲方法和我觉得站不住的消融部分
```

The skill routes itself: 组会/答辩/开题/中期/结题/会议/journal club keywords select the
scenario system; ambiguous asks get one clarifying question, never a guess.

### QA gate

Every deck passes two gates before delivery:

```bash
python skills/lyceum/scripts/qa_check.py deck.pptx     # programmatic: overflow (CJK-aware),
                                                        # off-canvas, overlaps, placeholders,
                                                        # font coverage, editability audit
# exit 0 = clean · 1 = errors · 2 = warnings only · --json for machine output
```

plus a render-and-inspect visual pass. The checker ships its own negative-test fixture
([`examples/qa-selftest/`](examples/qa-selftest/)) — seven planted defects, seven catches.

under 500 lines (push depth into `references/`).
